# 0001. 两数之和

来源：[力扣 1. 两数之和](https://leetcode.cn/problems/two-sum/description/)。下面为题意摘要，完整题面以原题为准。

## 1. 题意

给定整数数组 `nums` 和目标值 `target`，找出两个不同位置，使这两个位置的数相加等于目标值，返回它们从 0 开始的下标。

输入保证恰好存在一组答案，同一位置不能使用两次。两个下标的返回顺序不限。

## 2. 示例

| nums | target | 一种合法输出 |
| --- | --- | --- |
| `[2, 7, 11, 15]` | `9` | `[0, 1]` |
| `[3, 2, 4]` | `6` | `[1, 2]` |
| `[3, 3]` | `6` | `[0, 1]` |

第一组中，下标 0 和 1 对应的数相加为 9，因此返回 `[0, 1]`。第三组中的两个 3 数值相同、位置不同，允许配对。

## 3. 约束

- 数组长度在 2 到 10⁴ 之间。
- 数组元素与目标值的绝对值均不超过 10⁹。
- 恰好有一组有效答案。

## 4. 进阶

设计时间复杂度低于 O(n²) 的算法。
